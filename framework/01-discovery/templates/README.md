# Blank discovery templates

[Stage guide](../README.md)

Upload reusable blank templates here: engagement charter, stakeholder map, interview guide, role/persona card, observation and findings register, assumptions log, and `discovery-baseline.xlsx`.

Suggested workbook tabs: Instructions, Stakeholders, Findings, Task Inventory, Time Study, Systems and Data, Baseline Summary. Define source, date, units, sample size, and evidence status. Label illustrative rows separately from blank inputs. Completed project workbooks belong in the case study.

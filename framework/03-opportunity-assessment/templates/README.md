# Blank opportunity assessment templates

[Stage guide](../README.md)

Upload `opportunity-assessment.xlsx`, an AI-versus-rules decision tree, and a recommendation-memo template.

Workbook tabs: Instructions, Scoring Criteria, Hard Gates, Opportunities, Economics, Sensitivity, Ranking, Decisions. Include owner, objective, volume, baseline/assisted effort, adoption, loaded hourly cost, build effort, platform/model/support cost, data readiness, complexity, risk, score, and evidence confidence.

Separate inputs from formulas; include units and low/base/high assumptions. Keep hard risk gates separate from the weighted score. Leave unmeasured results blank and label any illustrative example.

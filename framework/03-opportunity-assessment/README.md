Explain how to compare process removal/redesign, existing product settings, deterministic automation, conventional ML, bounded LLM tasks, and agents. Start with access, ownership, and unacceptable-risk gates before weighted prioritization.

Compare value, frequency, effort, expected adoption, review burden, complexity, integration feasibility, data quality, process stability, support cost, and evidence confidence. Record both selected and rejected opportunities.

Include low/base/high assumptions for implementation cost, recurring platform/model/support costs, time capacity released, loaded staff cost, and realizable financial benefit. Salary-value estimates are not automatically cash savings.

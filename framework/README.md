# Reusable delivery framework

[Home](../README.md) · [Upload guide](../UPLOAD-GUIDE.md)

**Status: upload destinations ready.** Store the repeatable method here, not completed client/project evidence.

Upload visual method PDFs directly into the relevant stage. Put blank workbooks and document templates in its `templates/` folder. PDFs can contain all supporting images; separately reusable graphics can go in [shared assets](../assets/README.md).

| Stage | Purpose |
|---|---|
| [01 Discovery](01-discovery/README.md) | Understand the assignment, people, work and constraints |
| [02 Process and baseline](02-process-baseline/README.md) | Map and measure the current state |
| [03 Opportunity assessment](03-opportunity-assessment/README.md) | Choose worthwhile work and whether AI belongs |
| [04 Solution definition](04-solution-definition/README.md) | Define product requirements and delivery scope |
| [05 Architecture and governance](05-architecture-governance/README.md) | Make technology, data, control and ownership decisions |
| [06 Implementation](06-implementation/README.md) | Build and document the workflow |
| [07 Evaluation and testing](07-evaluation-testing/README.md) | Measure quality and test operational behavior |
| [08 Release and operations](08-release-operations/README.md) | Deploy, monitor and recover |
| [09 Adoption and handover](09-adoption-handover/README.md) | Enable users, reviewers and maintainers |
| [10 Outcomes and improvement](10-outcomes-improvement/README.md) | Measure value and decide what to change next |

Every method should identify its question, inputs, techniques, evidence, decision criteria, outputs, and next step. Evaluation, governance, and adoption planning should begin before development, not only in their numbered stages.

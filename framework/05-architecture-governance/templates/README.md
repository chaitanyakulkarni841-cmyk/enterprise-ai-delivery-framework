# Blank architecture and governance templates

[Stage guide](../README.md)

Upload a system/data-flow diagram template, architecture decision record, vendor comparison, permissions matrix, and `technology-risk-assessment.xlsx`.

Workbook tabs: Vendor Options, Architecture Choices, Data Inventory, Permissions, Risks and Controls, Decisions.

Decision fields: question, constraints, options, evidence, choice, trade-offs, residual risks, reversibility, owner, and review trigger. Control fields: risk scenario, impact, mitigation, enforcement location, verifying test, residual risk, and acceptance owner.

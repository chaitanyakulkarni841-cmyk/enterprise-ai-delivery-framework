# Blank adoption templates

[Stage guide](../README.md)

Upload a change-impact assessment, user quick-start, reviewer checklist, training agenda, practical exercises, competency checklist, maintainer guide, and handover record.

Suggested workbook: `adoption-outcomes.xlsx`, with Training, Competency, Usage, Feedback, Overrides, Benefits, and Improvement Backlog tabs. Record eligible tasks/users, actual use, successful completion, review time, corrections, ownership, and evidence.

# Blank process and baseline templates

[Stage guide](../README.md)

Upload a swimlane template, task inventory, time-study sheet, metric dictionary, root-cause worksheet, and data-readiness checklist. The main discovery/baseline workbook may remain in stage 01; link to it rather than maintaining a duplicate.

Fields: task ID, trigger, owner, system, volume, active minutes, waiting minutes, error/rework definition, source, sample size, observation period, sensitivity, permissions, assumptions, and evidence confidence.

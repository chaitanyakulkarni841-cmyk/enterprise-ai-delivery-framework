# Deployment, monitoring and maintenance

[Case overview](../README.md)

Upload deployment/setup instructions, release manifest, pilot checklist, monitoring/metric definitions, alert rules, cost records, incident runbook, rollback/reconciliation guide, ownership, and maintenance schedule. PDFs, spreadsheets, and text/YAML are welcome as appropriate.

Release records should identify commit, Make blueprint, prompts, model/settings, taxonomy, controls, sources, dataset/rubric, and evaluation report. Log task/release IDs and necessary diagnostics without sensitive raw content by default.

Document manual deployment honestly. Restoring a configuration does not reverse external side effects. Distinguish planned pilots, sandbox runs, and actual production activity.

# Evaluation datasets and labeling

[Evaluation index](../README.md)

Upload publication-approved development, held-out and adversarial test cases as CSV/JSONL, plus a dataset card and labeling guide. Describe expected category, priority, allowed destinations, review behavior, prohibited action, and scenario tags.

Cover normal, urgent-but-polite, ambiguous/multi-topic, missing-history, unsupported, and malicious-input cases. Record data origin, sampling, splits, duplicates, limitations, and labeling disagreements. Do not relabel previously inspected/tuned cases as unseen evaluation data.

# Editable source documents and visuals

[Assets index](../README.md)

Upload publication-safe editable source files for the case PDFs and diagrams, such as DOCX, PPTX, or diagrams.net files. Use filenames that match the corresponding exported PDF/image.

Remove hidden comments, tracked changes, speaker notes, credentials, and confidential content before publishing. The exported PDFs remain in their numbered report folders; this folder is for editable sources, not competing report versions.

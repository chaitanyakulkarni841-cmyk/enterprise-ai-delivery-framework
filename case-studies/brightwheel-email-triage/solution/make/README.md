# Make scenario exports

[Solution index](../README.md)

Upload your actual exported scenario JSON here. Suggested filenames, only when implemented: `triage.blueprint.json`, `evaluation-runner.blueprint.json`, `feedback.blueprint.json`, and `monitoring.blueprint.json`.

Include setup instructions for connections, permissions, destination channels/sheets, supporting state stores, scheduling, error settings, and sample test runs. Imported blueprints need environment-specific configuration.

Inspect hard-coded values, email content, IDs, private endpoints, and tokens before publishing. Record the scenario/prompt/model/configuration versions together. A placeholder or screenshot is not an importable implementation.

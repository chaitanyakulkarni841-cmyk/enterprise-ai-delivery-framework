# User, reviewer and maintainer materials

[Case overview](../README.md)

Upload PDF quick-start guides, reviewer playbooks, training decks, practice exercises, FAQ/troubleshooting, maintainer instructions, and handover checklists.

Teach how to complete a normal task, verify an AI draft, correct a misroute, escalate missing information, report a fault, and safely maintain the system. Include a deliberately flawed output exercise and recovery rehearsal where appropriate.

Record actual competency/adoption observations separately from training plans. Name business/source/system owners by role; use real identities only with permission. The adoption summary belongs in `../docs/09-adoption-handover/`.

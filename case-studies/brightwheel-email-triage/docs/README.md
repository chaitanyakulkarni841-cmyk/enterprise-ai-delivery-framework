# Case-study PDF reports

[Case overview](../README.md)

Upload each completed report in its numbered stage folder. The ten stages mirror the [reusable framework](../../../framework/README.md). Reports can include images, tables, screenshots, and diagrams.

Suggested reading pattern: summary → question → method → evidence → decisions/trade-offs → next step. Include status, version/date, assumptions, source references, and links to implementation/test evidence. Keep data tables and editable source assets outside the PDF as well when reproducibility matters.
